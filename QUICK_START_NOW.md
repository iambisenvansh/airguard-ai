## If Something's Wrong

**Q**: Still seeing Nagpur error?
**A**: Restart backend: Kill (Ctrl+C) and run `python backend_api.py` again

**Q**: Report doesn't appear in Reports page?
**A**: Make sure command response says "✅ Allowed" in green

**Q**: Report appears but no content?
**A**: Normal! Click Download to get the actual file. Database stores metadata only.
